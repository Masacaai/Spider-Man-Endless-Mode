# UI hunt: the game's UI and how to drive it (started 2026-10-13)

Goal (user): inventory all of the game's UI systematically, then pick the right widget for each Endless Mode need: a reward choice screen with descriptions, a loadout view, a wave/score HUD, run results, dock map icons and waypoints, prompts. The HUD notification box (slot messages) was never meant for menus.

## How the UI is built
- **Scaleform (Flash) movies.** `ui/export/HUD.gfx` is the HUD root; it imports `HUD/FlatMessages.gfx`, `HUD/ImageReveal.gfx`, `HUD/PIPClue.gfx`, `HUD/POIs.gfx`, `HUD/PhotoMode.gfx`, `HUD/PlaceablePrompts.gfx`, `HUD/QTEs.gfx`, `HUD/QuickSelect.gfx`, `HUD/Reticle.gfx`, `HUD/StreamOverlay.gfx`, `HUD/TargetLock.gfx` and `popups/CommTowerMenu.gfx`. Also found: `HUD/Objectives.gfx`, `HUD/Messages.gfx`, `HUD/Health.gfx`, `HUD/ExperienceMenu.gfx`, `HUD/EavesdropMenu.gfx`, `HUD/SpiderBotHUD.gfx`, `popups/IntelTowerMenu.gfx`. Identifier dumps: `recon/ui/*.identifiers.txt`; extracted movies: `tools/assets/ui/`.
- Texture lists: `configs/UIConfig/UIHUD.config`, `UIPopup.config` (e.g. `ui/textures/hud/pick_previews/*`, `ui/textures/popups/reward_bg.texture`). Menus: `configs/UIConfig/UISystemMenu.config`.
- **The HUD's managers** (ActionScript `HUD.managers.*`): AfterAction, CommTower, E3Lobby, FlatMessage, ImageReveal, PIPClue, POI, PhotoMode, PlaceablePrompt, QTE, QuickSelect, Reticle, SparkChallenge, StreamOverlay, TargetLock.
- **Button icons:** text tokens `[BTN_A]` `[BTN_B]` `[BTN_X]` `[BTN_Y]` (also L1/L2/R1/R2/L3/R3/LB/RB, `[BTN_MAP_WAYPOINT_SET]`, `[BTN_CANCEL]`) render as the active device's glyph (verified on DualSense). The movies know the devices: DEVICE_DUALSENSE, DEVICE_DUALSHOCK, DEVICE_MKB, DEVICE_XBOXONE, DEVICE_STEAMINPUT, DEVICE_STEAMDECK and others.

## Calling ActionScript from code (static RE, not yet called by us)
- **exe+1d1cee0 `Invoke(movie, &as_object, "Method", result, args, count)`** (167 call sites). Example: exe+77d130, the generic flat message, builds 3 values (text, two numbers clamped 0..1, probably a screen position) and calls Invoke on "ShowGenericMessage".
- **HUD root per player:** `[exe+7c2b5a0 + i*8]` (via exe+1f063a0 / exe+75e680). The generic-message element is `[root+0x1A0]`: movie at +0x10, AS object at +0x320, flags at +0x338.
- Argument values: 0x30 bytes, type u32 at +0x18 (2 bool, 5 number, 6 string), data at +0x20.
- Tools (built 2026-10-13): `uiroot` (the root's pointer fields with C++ class names from RTTI), `uiobj <addr>`, `uicall <root offset|addr> <Method> [args]` (numbers, true/false, "strings").
- Mission-script UI actions (each a short execute that leads to these calls): UITextMessageAction (exe+7e62f0), UIMediumMessageAction (exe+7f3a50), UITutorialMessageAction (exe+7f1e00), UITutorialPopUp (exe+13f1670), UIDynamicHelpPopUp (exe+13f0f50), UICounterAction (exe+7df940), UIProgressBarAction (exe+7dfe60), UICountDownAction (exe+7df360), UIMapPOIAction (exe+7f0e20), UIScoreboardAction (exe+7f1030), UIPickupPreviewAction (exe+7e07b0), UIMissionCompleteAction (exe+7ee7c0), UIUpdateCustomWaypointAction (exe+7efd10), UIEnableButtonInteractMessagesAction (exe+7e1d80). Also UITutorialPauseBegin/End, UIHUDCounterIntro/Updated/Complete, UIAfterActionPanel*, UIStreamOverlay*, UINewspaperPopupAction, UIBossHealthScanComplete.
