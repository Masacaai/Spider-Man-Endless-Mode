title: A bigger reward-pick screen with item media
labels: feature, ui, research
---

Reward picks use the notification box. The ideal is a near-fullscreen pop-up like the suit menu, showing the item's preview video/picture and description (item records hold preview video/image and icon, see GAME_INTERNALS).
The tutorial pop-up card (`UITutorialPauseBegin`, exe+13f1670) is a lead. None of the widgets found so far is big enough.
